# OctoFit Tracker API Configuration

## Overview

The Node.js API is configured to support both Codespaces and localhost environments with automatic detection and URL generation.

## Architecture

### Environment Detection

The API automatically detects the environment and configures accordingly:

- **Codespaces**: Detects `CODESPACE_NAME` environment variable
- **Localhost**: Uses `localhost` as fallback

### API Base URL

```typescript
// Codespaces (when CODESPACE_NAME is available)
https://$CODESPACE_NAME-8000.app.github.dev

// Localhost (fallback)
http://localhost:8000
```

### CORS Configuration

The API is configured to accept requests from:

- `http://localhost:5173` (Vite development server)
- `http://localhost:3000` (alternative localhost)
- `https://$CODESPACE_NAME-5173.app.github.dev` (Codespaces frontend)

## Server Configuration

- **Port**: 8000
- **Environment**: Automatic detection via `CODESPACE_NAME` environment variable
- **Database**: MongoDB on `mongodb://localhost:27017/octofit`

## API Endpoints

### Health Check
```bash
GET /api/health
```

Returns server status and API base URL.

### Users API

**Get all users**
```bash
GET /api/users
```

**Get user by ID**
```bash
GET /api/users/:id
```

**Create user**
```bash
POST /api/users
Content-Type: application/json

{
  "username": "string",
  "email": "string"
}
```

**Update user**
```bash
PUT /api/users/:id
Content-Type: application/json

{
  "username": "string",
  "email": "string"
}
```

**Delete user**
```bash
DELETE /api/users/:id
```

### Activities API

**Get all activities**
```bash
GET /api/activities
```

**Get activities by user**
```bash
GET /api/activities/user/:userId
```

**Get activity by ID**
```bash
GET /api/activities/:id
```

**Create activity**
```bash
POST /api/activities
Content-Type: application/json

{
  "userId": "string (ObjectId)",
  "activityType": "run|walk|cycling|swimming|gym|yoga|other",
  "duration": "number (minutes)",
  "date": "ISO timestamp (optional)",
  "notes": "string (optional)"
}
```

**Update activity**
```bash
PUT /api/activities/:id
Content-Type: application/json

{
  "activityType": "string",
  "duration": "number",
  "date": "ISO timestamp",
  "notes": "string"
}
```

**Delete activity**
```bash
DELETE /api/activities/:id
```
